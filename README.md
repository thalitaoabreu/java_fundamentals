# Java Studies ☕

Repositório dedicado aos meus estudos de Java e ao desenvolvimento das minhas habilidades em programação Back-End.

Aqui compartilho exercícios, desafios e pequenos projetos desenvolvidos durante minha jornada de aprendizado.

## Conteúdos estudados

- Fundamentos da linguagem Java
- Variáveis, tipos e operadores
- Estruturas condicionais
- Estruturas de repetição
- Métodos e funções
- Arrays e coleções
- Programação Orientada a Objetos
- Tratamento de exceções

## Projetos práticos

| Projeto | Descrição |
|---|---|
| Calculadora de compras | Cálculo de valores, descontos e parcelas |
| Jogo de adivinhação | Jogo com número aleatório e limite de tentativas |
| Caixa eletrônico | Simulação de operações bancárias |

## Objetivo

Consolidar meus conhecimentos em Java e avançar no desenvolvimento de aplicações Back-End utilizando Spring Boot.

## Como executar

1. Clone o repositório:

   git clone https://github.com/thalitaoabreu/java_fundamentals.git

2. Abra o projeto na sua IDE.

3. Navegue até o exercício desejado.

4. Execute a classe que contém o método main.

*Este repositório está em constante evolução, acompanhando meu progresso nos estudos.*
